# Student Exam Performance Analysis

# 🎯 Project Overview
Student performance data ka analysis karke exam results
ko affect karne wale factors dhundhe hain.

# Business Questions
- Study hours ka exam score pe kya asar hai?
- Attendance improve karne se score badhta hai?
- Parental involvement ka kitna impact hai?
- Gender wise performance mein kya fark hai?

# Key Metrics
| Metric | Value |
|--------|-------|
| Avg Exam Score | 67.24 |
| Avg Study Hours | 19.98 |
| Total Students | 6,607 |
| Avg Attendance | 79.98% |
| High Performers | 43 |

# Key Insights
- Study hours badhne se exam score improve hota hai ✅
- High attendance = Better performance ✅
- Parental involvement ka weak impact hai ❌
- Gender wise performance similar hai
